# gemini-util-skills

Coleção de skills de propósito diverso para uso no Chat do Google Gemini, com o objetivo de facilitar e padronizar tarefas recorrentes.

## Estrutura

Cada skill fica em sua própria pasta dentro de `skills/`, contendo as instruções a serem utilizadas no Gemini.

```
skills/
  <nome-da-skill>/
    README.md
```
